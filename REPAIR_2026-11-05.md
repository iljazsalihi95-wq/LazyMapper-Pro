## Implemented

- Same-origin Cloudflare gateway with verified Access JWTs, explicit administrator
  email allowlist, origin checks, required rate limiter, restricted routes, fixed
  upstreams, bounded request bodies and timeouts. Secrets are injected server-side.
- Reuses the existing Sheets/Apps Script and persistent analyzer queues; no new
  server database or repository. Production cloud deployment is pending sign-in.
- Pinned-DNS, exact-host authenticated metadata/M3U transport in the existing Python
  backend. HTML/oversized responses and unauthorized destinations are refused.
- M3U selection, JSON/M3U exports, selected untested import with truthful NOT TESTED
  status, optional WORKING-only transfer, dedupe within the submitted dataset,
  acknowledged 40-item checkpoints, STOP and resume. Credentials and pending
  playlists are no longer saved as Xtream import payloads in sessionStorage.
- Full-content SHA-256 import fingerprint replaces the old first/last/count-only
  fingerprint. Retry stops on auth/rate-limit failures. Acknowledged in-flight batches
  still advance the checkpoint when STOP arrives during their network request.
- Xtream series opens episode lists via get_series_info and creates episode URLs,
  with countries, JSON export, STOP and strict list-shape validation.
- Stalker read/test/import STOP, duplicate page-entry suppression, bounded Apps
  Script job pages, statusJob alias and manual resume of stopped auth/rate jobs.
- Server list pages render progressively rather than withholding all data until
  the last network page. Main view paginates 100 rows; explicit server-ID mismatches
  are refused and header rows are omitted. JSON exports preserve destination context.
- Separate server player now reads STREAM_URL_CMD, including ffmpeg-prefixed URLs.
  It previously ignored the actual URL column returned by the live API.
- Player lifecycle cleanup, bounded HLS recovery and playback-progress status.
  Browser raw TS is explicitly unsupported without an appropriate engine; Android
  retains Media3/LibVLC. Native Media3 confirms a rendered frame; LibVLC distinguishes
  startup from advancing media time. Browser playback was tested with generated VP8.
- Five AppCreator HTML entry points are reproducibly generated from current index.
  CI checks synchronization, Worker tests and functional integration before APK build.
