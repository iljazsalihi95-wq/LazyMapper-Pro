# Third-party libraries

- AndroidX Media3 and WorkManager: Android Open Source Project, Apache-2.0.
  https://developer.android.com/jetpack/androidx
- LibVLC Android (`org.videolan.android:libvlc-all:3.6.0`): VideoLAN.
  https://code.videolan.org/videolan/vlc-android
  https://www.videolan.org/legal.html
  LibVLC includes native components and codecs with their own notices. Before redistributing a release APK, review the complete bundled licenses and fulfill applicable LGPL/relinking/source requirements. This checkpoint is a debug build, not distribution clearance.
- FFmpeg/FFprobe are installed only on the private backend, not bundled into the Android application. See the distribution's FFmpeg build configuration and license notices: https://ffmpeg.org/legal.html

No third-party stream, channel logo, playlist or service credentials are bundled by this checkpoint.
