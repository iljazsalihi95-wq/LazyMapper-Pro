# LazyMapper Pro

LazyMapper Pro — IPTV playlist management and mapping.

## Architecture
- Stalker
- Xtream Codes
- M3U/M3U8
- SERVER_01–20
- LazyTV Pro device assignment

The frontend does not store admin passwords, IPTV credentials, MAC addresses, or private API keys in the repository.

SERVER_02 and SERVER_03/04 are used as real-content integration references. Device registration remains disabled until the existing LazyTV Pro backend registration endpoint/schema is connected.
